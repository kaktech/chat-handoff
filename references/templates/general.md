# General template

Use for mixed or unclassifiable chats, planning, advice, brainstorming, everyday tasks.

## Emphasis

Goal, Decisions made, Open items. Keep Key facts to what the next reply truly needs.

## Brief skeleton

```
# Handoff: <topic> | general | <tier>
## Goal
<one or two sentences: what the person ultimately wants, and why if stated>
## Decisions made
- <settled choice> (reason if given)
## Key facts
- <name, number, constraint, definition, or pasted data that matters, verbatim>
## Current state
- Done: ...
- In progress: ...
- Blocked: ... (by what)
## Open items / next step
1. <first thing the new chat should do>
## Style and preferences
- <tone, format, length, language>
## Files and artifacts
- <name: what it is, where, last change>
## Do not redo
- <thing tried or rejected>: <reason>
Resume: Continue from Open items. Do not re-ask answered questions. Treat Decisions made as settled unless I say otherwise.
```

## Section prompts

- Goal: the end result, not the last question asked.
- Decisions: only choices the user confirmed or clearly accepted. Suggestions the user ignored go nowhere.
- Key facts: dates, budgets, quantities, names, preferences that constrain answers.
- Next step: one concrete action. If the chat ended on a question to the user, that question is the next step.
